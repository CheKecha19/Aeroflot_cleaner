# Система аудита и синхронизации пользователей Active Directory с внешними сервисами

Данный проект предназначен для автоматического сравнения учётных записей **Active Directory (AD)** с данными из **1С**, **Контур.Диадок** и **Сфера Курьер**, а также со **штатным расписанием**. Программа выявляет расхождения, дубликаты и «мёртвые души» (активных пользователей в системах, отсутствующих в AD), формирует подробный Excel‑отчёт и логирует все этапы работы.

---

## 🚀 Возможности

- **Автоматический экспорт из Active Directory**  
  – через PowerShell получает всех пользователей, определяет статус активности.  
  – разделяет активных на **сотрудников** (кампус) и **ГПХ** (по DN-атрибуту).  
  – сохраняет результаты в TXT и Excel.

- **Гибкая загрузка данных из систем‑источников**  
  – **1С**: чтение Excel‑отчёта нового формата (столбцы «Пользователь», «Недействителен»).  
  – **Контур.Диадок** и **Сфера Курьер**: **два режима** – из Excel (самый свежий файл в папке) или **через официальные API** (при наличии ключей доступа).  
  – **Штатное расписание**: любой Excel‑файл с ФИО сотрудников.

- **Интерактивный выбор**  
  – какие системы проверять (1С, Сфера Курьер, Контур.Диадок, всё сразу).  
  – какие категории сотрудников учитывать (все, только штатные, только ГПХ).

- **Нормализация ФИО**  
  – замена «ё» → «е», приведение к верхнему регистру, выделение фамилии и имени (отчество игнорируется).  
  – позволяет корректно сравнивать записи из разных источников.

- **Детальный анализ**  
  – внутренние дубликаты в каждой системе.  
  – пересечения между AD и каждой системой.  
  – **пользователи для удаления**: активные в системе, но отсутствующие в AD.  
  – несоответствия между AD и штатным расписанием (лишние в AD).

- **Формирование отчёта в Excel**  
  – основной лист со сводными данными.  
  – отдельные листы: «сравнение AD и Штатки», «дубли в [система]», «удалить из [система]».  
  – файл сохраняется с меткой времени в папке `вывод/`.

- **Полное логирование**  
  – два лог‑файла: общий (`log.txt`) и отдельный для экспорта AD (`ad_export.log`).  
  – настраиваемый уровень детализации.

## 📁 Требования

- **Python** 3.7 или выше  
- **PowerShell** (для экспорта AD; доступ к контроллеру домена)  
- **Библиотеки Python** (см. `requirements.txt`)  
- Для работы **API Контур.Диадок**:  
  – API‑ключ с правами администратора организации.  
- Для работы **API Сфера Курьер**:  
  – логин и пароль администратора системы.

## ⚙️ Установка и настройка

1. **Клонируйте репозиторий** (или скопируйте файлы проекта).

2. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Настройте переменные окружения** – создайте файл `.env` в корневой папке проекта (рядом с `main.py`). Пример заполнения:
   ```ini
   # Контур.Диадок
   DIADOC_API_KEY=ваш_секретный_ключ
   DIADOC_BOX_ID=          # оставьте пустым для автоматического определения
   DIADOC_API_BASE_URL=https://diadoc-api.kontur.ru

   # Сфера Курьер
   SFERA_USERNAME=ваш_логин_администратора
   SFERA_PASSWORD=ваш_пароль
   SFERA_API_BASE_URL=https://api.sfera-docs.ru
   ```
   Если вы **не планируете использовать API**, оставьте ключи пустыми – программа автоматически переключится на чтение из Excel.

4. **При необходимости отредактируйте `config.py`**:
   - `MAX_FILE_AGE_DAYS` – максимальный «возраст» входных файлов (по умолчанию 180 дней).  
   - `USE_DIADOC_API`, `USE_SFERA_API` – включение/отключение API-режима (можно оставить `False`, тогда всегда будет использоваться Excel).  
   - Пути к папкам (`INPUT_DIR`, `OUTPUT_DIR` и др.) – в большинстве случаев менять не нужно.

5. **Подготовьте входные данные**:
   - Создайте в папке `эксельки` следующие подпапки (если их нет):
     - `штатка/` – для файлов штатного расписания (любой Excel с колонкой ФИО).  
     - `1С/` – для выгрузки из 1С (формат описан ниже).  
     - `эдо_контур_диадок/` – для Excel‑файлов из Контур.Диадок (если не используете API).  
     - `эдо_сфера_курьер/` – для Excel‑файлов из Сфера Курьер (если не используете API).  
   - **Важно:** программа автоматически выберет **самый свежий** файл в каждой папке, поэтому **имена файлов могут быть любыми**. Дата изменения файла не должна быть старше `MAX_FILE_AGE_DAYS`.

## 🖥️ Использование

1. **Поместите исходные файлы** в соответствующие папки (см. выше).

2. **Запустите программу**:
   ```bash
   python main.py
   ```

3. **Следуйте интерактивным подсказкам**:

   ```
   ==================================================
   Выберите опции для проверки (через пробел):
   0 - Всё
   1 - 1С
   2 - Сфера Курьер
   3 - Контур Диадок
   ==================================================
   Ваш выбор: 
   ```
   Введите цифры через пробел (например, `1 3`).

   Затем выберите тип сотрудников:
   ```
   ==================================================
   Выберите тип сотрудников для проверки (через пробел):
   0 - Все
   1 - Сотрудники
   2 - ГПХ
   ==================================================
   Ваш выбор: 
   ```

4. **Дождитесь завершения**. Программа:
   - выполнит экспорт из AD (всегда, независимо от выбора);
   - загрузит данные из выбранных систем;
   - проведёт анализ;
   - сформирует Excel‑отчёт в папке `вывод/`.

5. **Откройте полученный файл** `результат_обработки_...xlsx` – все результаты структурированы по листам.

## 📊 Описание выходных данных

### Основной лист (`сравнение пользователей`)
Сводная таблица со следующими колонками:

| Колонка | Описание |
|--------|----------|
| Штатное_ФИО | ФИО из штатного расписания |
| AD_сотрудники | ФИО активных сотрудников AD |
| AD_Статус_сотрудники | «Активна» / «Заблокирована» |
| AD_ГПХ | ФИО активных ГПХ |
| AD_Статус_ГПХ | «Активна» / «Заблокирована» |
| Контур_Диадок_ФИО | ФИО из Контур.Диадок |
| Контур_Диадок_Администратор | да/нет |
| Контур_Диадок_статус | активна / заблокирована |
| Сфера_Курьер_ФИО | ФИО из Сфера Курьер |
| Сфера_Курьер_Активен | Да/Нет |
| Сфера_Курьер_Администратор | Да/Нет |
| 1C_ФИО | ФИО из 1С |
| 1C_Активен | Да/Нет |

### Лист `сравнение AD и Штатки`
Показывает сотрудников, которые **активны в AD, но отсутствуют в штатном расписании**.  
Колонки: `ФИО_AD`, `Статус` (фиксированный комментарий).

### Листы `дубли в ...`
Содержат записи с повторяющимися ФИО внутри соответствующей системы (Контур.Диадок, Сфера Курьер, 1С).  
Повторы определяются после нормализации.

### Листы `удалить из ...`
Список **активных пользователей** системы, **ФИО которых нет ни в AD‑сотрудниках, ни в AD‑ГПХ**.  
Этих пользователей рекомендуется деактивировать или удалить.

## 🔌 Работа через API

### Контур.Диадок
Включите `USE_DIADOC_API = True` в `config.py` и укажите валидный `DIADOC_API_KEY` в `.env`.  
Клиент автоматически:
- определяет BoxId (первый доступный ящик организации);
- загружает всех сотрудников с пагинацией;
- преобразует ответ в DataFrame, совместимый с Excel-форматом (ФИО, администратор, статус блокировки).

**Требования к ключу**: API‑ключ должен принадлежать администратору организации и иметь права на чтение сотрудников.

### Сфера Курьер
Включите `USE_SFERA_API = True` в `config.py` и укажите `SFERA_USERNAME` / `SFERA_PASSWORD` в `.env`.  
Клиент:
- выполняет аутентификацию (POST /api/auth/logon);
- получает список ролей, определяет ID роли «Администратор системы»;
- загружает всех пользователей (POST /api/helper/userList);
- формирует DataFrame с колонками: ФИО, активность, признак администратора.

**Важно**: если API недоступен или возвращает ошибку, а флаг использования API включён, программа **выбросит исключение** (по замыслу автора). Чтобы автоматически переключиться на Excel, установите соответствующий флаг в `False`.

## 🧪 Особенности обработки

- **1С (новый формат)**  
  Программа ищет строку с заголовком **«Пользователь»** в первом столбце листа «Лист_1». Данные считываются, начиная со следующей строки.  
  - Столбец A → ФИО  
  - Столбец E («Недействителен») → «Нет» = активен, «Да» = неактивен  
  Служебные записи (содержащие «сервис», «robot» и т.п.) отбрасываются.

- **Контур.Диадок (Excel)**  
  Автоматически ищет колонки по ключевым словам («ФИО», «Администратор», «Дата блокировки»).  
  - Если дата блокировки пуста → статус «активна», иначе «заблокирована».  
  - Администратор преобразуется в «да»/«нет».

- **Сфера Курьер (Excel)**  
  Ищет колонки «ФИО», «Активен», «Администратор». Приводит значения к «Да»/«Нет».

- **Штатное расписание**  
  Любой Excel с колонкой, содержащей ФИО. Программа пытается угадать нужный столбец (по вхождению «ФИО», «Ф.И.О.» и т.д.).

## 🧰 Логирование и отладка

Все действия записываются в файлы:

- `вывод/log/log.txt` – общая информация о работе приложения.
- `вывод/log/ad_export.log` – детали экспорта из Active Directory.

Уровень логирования можно изменить в `config.py`:
```python
LOG_LEVEL = logging.INFO   # DEBUG – для максимальной подробности
```

При возникновении ошибок программа старается продолжить работу, создавая пустые DataFrame и записывая предупреждения в лог.

## 🛠️ Возможные проблемы и их решение

| Проблема | Решение |
|--------|---------|
| **PowerShell не возвращает пользователей AD** | Проверьте права учётной записи, от которой запускается скрипт. Альтернативный метод `Get-ADUser` требует модуля ActiveDirectory. |
| **API‑ключ не работает (401)** | Убедитесь, что ключ корректен и не истёк. Проверьте, что ключ выдаётся от имени администратора организации. |
| **Не найден актуальный файл в папке** | Поместите файл с датой изменения не старше 180 дней. При необходимости измените `MAX_FILE_AGE_DAYS`. |
| **Неверное распознавание колонок в Excel** | Переименуйте заголовки столбцов в стандартные («ФИО», «Администратор» и т.п.) или отредактируйте функции `load_*_from_excel` в `utils.py`. |
| **Программа долго выполняется** | Экспорт AD и загрузка через API могут занимать время. Используйте индикаторы прогресса (tqdm). |

## 📝 Пример использования

1. Пользователь поместил в `эксельки/1С/` файл `Users.1C.xlsx` (дата изменения: сегодня).

3. В `эдо_сфера_курьер/` – `users_sfera.xlsx`.  
4. Запускает `python main.py`, выбирает `0` (всё) и `0` (все типы сотрудников).

6. В листе «удалить из Сфера Курьер» оказывается Иванов И.И. – активен в Сфере, но его нет ни в AD‑сотрудниках, ни в AD‑ГПХ.  
7. Администратор использует этот список для деактивации учётной записи.
